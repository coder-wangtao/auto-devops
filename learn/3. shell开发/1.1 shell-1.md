1、shell变量

 bash shell把任何存储在变量中的值，再未经声明的数据类型的情况下，都视为字符串

1）变量的命名  a、由英文字母，数字，_（底线）组成   b、大小写有区分  c、不可以数字开头

2）设定变量   

​	#num=hello   

​	#num1 = hell01 //错误   

​	如何声明一个变量 ,使用declare    

​	a、bash shell把任何存储在变量中的值，再未经声明的数据类型的情况下，都视为字符串   

​	例子：     

​		#a=3     

​		#b=4     

​		#c="$a*$b"     

​		#echo $c

​	 b、设置字符串变量的时候，用双引号或单引号把变量值括起来    

​			例子：      

​				#name=dog      

​				#name1=dog pig      

​				#name2="dog pig"      

​				#name3='dog pig apple'      

​				#name4="\"dog\""

​		 c、declare -i       

​			  例子1：     

​			  	#a=3     

​				  #b=4     

​                  #declare -i c="$a*$b"     

​                  #echo $c       

​               例子2：     

​			       #sum=100+50     

​                   #echo  $sum     

​                   #declare -i  sum=100+50     

​                   #echo $sum

​		    d、declare  -a     

​                  #declare -a  arrayvar2=(a b c d e)   //array[0]="a"      

​                  #echo  $arrayvar2[1]   //错误写法        

​                  #echo  ${arrayvar2[1]}    

​                  #echo  ${arrayvar2[1+1]}         

​                  #echo ${arrayvar2[@]}        取出所有的元素值   

​                  #echo ${#arrayvar2[@]}    看数组有多少个元素

​                  如果数组元素是字符串，要看字符串长度的话，可以使用如下的办法    

​                  #echo ${#arrayvar2[1]}

 			e、declare -r(只读,unset无法取消)    

​					#declare -r  numname=pigpig    

​					#numname=test

​			  f、declare -x  //相当于export这个变量    

​					#declare  -x  tename="hello world"    

​					#tename1=hell    

​					#touch  sh.sh  //内容如下      

​								#!/bin/bash      

​								echo -e "tename=$tename \n"      

​								echo -e  "tename1=$tename1 \n"   

​                    #./sh.sh   执行脚本

​				 g、变量之间传递值    

​					例子1：    

​						#n1=2    

​						#n2=n1    

​						#echo $n2    

​					例子2：    

​						#n1=2    

​						#n2=$n1    

​						#echo $n2  

​					h、declare  -p  变量名  //查看变量类型（属性）

​	2、读取变量

​		   $变量名  ${变量名}   

​			#hename=jacky   

​			#echo $henameMMMMM   

​			#echo ${hename}MMMMM      

​			当变量名后面紧跟着英文字母和数字的时候，请使用｛｝隔开   

​			而对于其他字符可以不用{}隔开     

​			#henmae=jim   

​			#echo  /home/$jim/Desktop

​		3、unset取消变量

   		#n1=2   

​		   #echo  $n1   

​           #unset n1   #echo  $n1

​       4、变量和单引号、双引号  

​			双引号具有置换变量的功能，而单引号则没有  

​			例子：  #./var_yinhao.shvar_yinhao.sh 

​			内容如下

​					#!/bin/bash

​					num1=110

​					echo -e "\$num1=$num1 \n"

​					echo -e '\$num1=$num1 '

​			提醒：awk和sed引用的时候要注意，不是双引号置换
