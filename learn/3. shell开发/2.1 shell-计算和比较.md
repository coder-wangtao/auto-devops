对同样的两个数，我用>和-gt来做比较，为什么会出现不一样的情况，这两个是否有区别？脚本内容如下：

\#!/bin/bash

\#function compare

\#author xxx 20131203

a=1

b=2

declare -i c=3

declare -i d=4

echo "a=$a b=$b c=$c d=$d"

\#使用>进行比较

echo "使用>进行比较"

if [ "$a" > "$b" ];then

​    echo "a > b"

else

​    echo "a < b"

fi

if [ "$c" > "$d" ];then

​    echo "c > d"

else

​    echo "c < d"

fi

\#使用-gt进行比较

echo "使用-gt进行比较"

if [ "$a" -gt "$b" ];then

​    echo "a > b"

else

​    echo "a < b"

fi

运行脚本，看输出的结果！

如果你用">"或“<”来进行数字的比较，请将他转义,别忘了他们是linux系统表示数据流重定向的符号
