Ansible循环和条件

1、通常情况下，当任务出现失败的时候，ansible会在该主机上中止play的其余部分并且跳过所有后续任务。在任务出现错误的时候，除默认处理，我们也可以采取：忽视错误、强制执行任务等办法忽视错误的语法：

任务失败忽略错误剧本例子：



\---

\- name: 忽略错误执行play的后续模块动作

 hosts: web 

 tasks: 

  \- name: 重启服务

   service:

​    name: htttp

​    state: stopped

   ignore_errors: yes 

 

  \- name: 重启ftp服务

   service:

​    name: vsftpd

​    state: restarted



2、如果任务失败并且play在该主机上中止，则收到play中早前任务通知的处理程序将不会执行。如果设置了force_handlers: yes，那任务失败也会执行处理程序。

\---

\- name: 设置force_handlers为yes,让本不执行的处理程序执行起来

 hosts: web 

 force_handlers: yes 

 tasks: 

  \- name: 重启服务

   service:

​    name: httpd

​    state: restarted

   notify: restart vsftpd

 

  \- name: 执行一条命令

   command: dateee

  

 handlers:

  \- name: restart vsftpd

   service:

​    name: vsftpd

​    state: restarted



3、指定任务失败条件剧本

\---

\- name: 测试faild_when

 hosts: web 

 tasks: 

  \- name: 关闭ftp服务

   service:

​    name: vsftpd

​    state: stopped

   

  \- name: 判断端口是否关了

   shell: /usr/local/scripts/port.sh 21

   register: port_result 

   failed_when: "'port is not exist' in port_result.stdout"



4、指定条件change

可以在任务中使用changed_when可用于控制任务在何时报告它已进行了更改

\---

\- name: 测试changed_when

 hosts: web 

 tasks: 

  \- name: 判断端口是否关了

   shell: /usr/local/scripts/port.sh 21

   register: port_result 

   changed_when: "'port is exist' in port_result.stdout"

   notify:

​    \- restart_http



 handlers:

  \- name: restart_http

   service:

​    name: httpd

​    state: restarted



5、块条件的使用

在playbook中，块是对任务进程逻辑分组的字句，可用于控制任务的执行方式。任务块可以含有when关键字将某一条件应用到多个任务。

\---

\- name: block and when example

 hosts: web 

 tasks:

  \- name: block when

   block: 

​    \- name: 写一行到文件去

​     lineinfile: 

​      dest: /tmp/d.log

​      line: tttttt

​      state: present



​    \- name: 下载文件

​     get_url:

​      url: ftp://192.168.31.147/pub/url.txt

​      dest: /tmp/new.txt



   when: ansible_distribution == "Redhat"





6、block-rescue-always

\---

\- name: block rescue always example

 hosts: web 

 tasks:

  \- name: block when

   block: 

​    \- name: shell-1

​     shell: 

​      cmd: shell-1

   

   rescue:

​    \- name: rescue

   always:
