Ansible模版和角色

一、模版介绍

1、 ansible中管理文件，可以通过模块，比如lineinfile/blockinfile来进行文件的管理但更强大的方式则是通过为其构建模版。ansible将jinja2模版系统用于模版文件。Jinja2模版由多个元素组成:数据、变量、表达式。在呈现Jinja2模版时，变量和表达式被替换为对应的值。模版中使用的变量可以在playbook的vars部分中指定。可以将受管主机的事实用做模版中的变量。 Jinja2模版可用于自定义要在受管主机上部署的配置文件，文件可以通过template模块部署到受管主机上。

2、ansible将Jinja2模版系统用于模版文件。Ansible使用Jinja2语法来引用playbook中的变量。

例子：

\---

\- name: 模版模块的使用例子

 hosts: web 

 vars:

  ssh_port: 222 

 tasks:

  \- name: 使用template,下发文件到受管机

   template:

​    \#src: /etc/ansible/example/template.j2

​    \#src: template.j2

​    src: ./template.j2

​    dest: /tmp/test.txt

提醒： 使用template模块进行配置文件下发时，src参数不指定路径的情况下，会在当前路径的templates目录下找。



模版文件template.j2部分内容如下：

Port {{ ssh_port }}

\#AddressFamily any

ListenAddress {{ ansible_facts['default_ipv4']['address'] }}  

\#ListenAddress {{ ansible_default_ipv4.address }}

\#ListenAddress ::

HostKey /etc/ssh/ssh_host_rsa_key

\#HostKey /etc/ssh/ssh_host_dsa_key

HostKey /etc/ssh/ssh_host_ecdsa_key

HostKey /etc/ssh/ssh_host_ed25519_key



模版例子2:

\---

\- name: 模版模块的使用例子(for循环) 

 hosts: web 

 vars:

  users:

   \- jim

   \- tom

   \- root

 tasks:

  \- name: 使用template,下发文件到受管机

   template:

​    src: ./template_user.j2

​    dest: /tmp/user.txt



模版文件./template_user.j2内容如下

{# 演示for循环 #}  

{% for myuser in users if not myuser == "root" %}

user number {{ loop.index }} - {{ myuser }}

{% endfor %}



模版例子3

\---

\- name: 模版模块的使用例子(json格式的输出) 

 hosts: web 

 vars:

  users:

   \- jim

   \- tom

   \- root

 tasks:

  \- name: 使用template,下发文件到受管机

   template:

​    src: ./template_json.j2

​    dest: /tmp/user.txt



模版文件./template_json.j2

{# 演示for循环 #}  

{% for myuser in users if not myuser == "root" %}

{{ myuser | to_json }}

{% endfor %}



二、角色

剧本引用角色例子：

\---

\- name: 利用角色安装redis 

 hosts: web 

 roles:

 \- role: redis

  rpmdir: /usr/local/src/ttt



三、剧本部署环境时的要点

并行和串行

\#可以在ansible.cfg中defaults配置段中增加forks=1

\#也可以在剧本运行时指定 --forks 1

\---

 \- name: 测试forks并发设置

  hosts: haproxy

  tasks:

  \- name: 关闭服务

   service:

​    name: httpd

​    state: stopped

#time  ansible-playbook   forks.yml   --forks 1

#time  ansible-playbook   forks.yml

通过运行如上的两条命令，感受下并行情况下运行耗时



串行脚本例子：

---

 \- name: 测试serial等相关参数

  hosts: haproxy

  \#serial: 1

  tasks:

  \- name: 关闭服务

   service:

​    name: httpd

​    state: stopped

   

  \- name: 开启服务

   service: 

​    name: htttpd

​    state: started
