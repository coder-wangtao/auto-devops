SAMBA

1、samba的安装、启动和关闭

#systemctl enable smb.service        #设置开机启动
#systemctl start smb.service            #开启服务

#systemctl status smb    #查看状态

2、参数和配置例子

1)全局参数

[global]    security = share|user|server    

share  没有设置帐号和密码    

user     设置主机的密码文件做为登入的验证文件     

server  由其他服务端做登录验证判断

hosts allow = 127.               192.168.0.   

2)共享段例子

[data]

path = /home/username	(共享路径）

comment = tech	（注释）	

public = no	(不公开，有密码才能进 类似guest ok = no）  	

valid users = @t	(访问权限为t组）  	

write list = @t	(写权限为pj组）

备注：客户端连接时，显示的是data名，而非username;修改配置可以先testparm下（检查配置文件）。

系统权限也要做好匹配（系统权限，selinux,iptables）

3)增加samba用户

a、要先增加系统帐号

​     useradd   smbuser  -s  /bin/false; passwd  smbuser

b、加入smb

​	smbpasswd   -a   smbuser

备注：smb用户与系统上帐号的密码无关，修改系统密码不影响smb用户之前设置的密码.

pdbedit    -L     //查看哪些samba用户

pdbedit    -x     -u    smbuser    //删除smbuser

3、samba的客户端使用

1:）查看共享

smbclient  -L      //IP

2）挂载共享

mount -t cifs -o username=guest,password=guest    //192.168.116.3/img                        /smb

客户端在挂载的时候报错的话，注意看下服务端和客户端是否都安装了cifs-utils包

3）随机启动挂载

在/etc/fstab文件中写入

//ip/devops   /mnt/dev    cifs     defaults,username=silene,password=redhat    0    0
