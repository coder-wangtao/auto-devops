4、跳转

1）Redirect Permanent /  http://hellen.linux.com当你访问hellen2.linux.com时跳转到helle.linux.com

<VirtualHost *:80>

​    DocumentRoot "/www/hellen2.linux.com"

​    ServerName hellen2.linux.com

​    Redirect    Permanent    /   http://hellen.linux.com

​    ErrorLog logs/hellen2.linux.com-error_log

​    CustomLog logs/hellen2.linux.com-access_log common

</VirtualHost>

注意确认日志中出现的记录！301指永久重定向，302指临时重定向。跳转的目的地址，别忘了写http协议

2） 利用rewriteengine来做跳转

<VirtualHost *:80>*

​	DocumentRoot "/www/hellen3.linux.com"

​    ServerName hellen3.linux.com

​    ErrorLog logs/hellen3.linux.com-error_log

​    CustomLog logs/hellen3.linux.com-access_log common

​    rewriteengine on        rewriterule ^(.*)$  http://hellen.linux.com$1   //对应跳转        *

​	#rewriterule ^(.*)$  http://hellen.linux.com/     //统一跳转

</VirtualHost>

5、访问控制

1）order 方式Apache提供基于主机的目录级和文件级访问控制

主机说明文件应该包括：点式数字地址，网络/子网掩码，主机和域Order提供“次序”控制

例如：只有允许那些ip地址属于example.com 域内的主机（station2 和 station3 除外），访问/var/www/html/internal。<Directory /var/www/html/internal> 

order allow,deny

 allow from .example.com

 deny from station2.example.com   station3.exmple.com

</Directory>

2）规则

order allow,deny	允许明确指定的“allow”客户，拒绝其他所有客户；若同时匹配allow 和 deny，则被拒绝。(白名单)

order deny,allow	拒绝明确指定的“deny”客户，允许其他所有客户；若同时匹配allow 和 deny，则被允许。（黑名单）

3）例子

例子1：允许所有客户端访问：

Order allow,deny

Allow from all

例子2：拒绝ip为10.20.30.40 和来自.apple.com 域的客户端访问。其他客户端都可以正常访问。

Order deny,allow

Deny from 10.20.30.40

Deny from .apple.com

例子3：仅允许192.168.1.0/24 网段客户端访问，但其中 ip为192.168.1.100不能访问。

Order allow,deny

Allow from 192.168.1.0/24

Deny from 192.168.1.100



Order deny,allow

Deny from 192.168.1.100

Allow from 192.168.1.0/24
