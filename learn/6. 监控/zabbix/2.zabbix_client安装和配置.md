zabbix的安装和配置

https://www.zabbix.com/download?zabbix=6.0&os_distribution=centos&os_version=8&components=agent&db=&ws=

 

a. Install Zabbix repository

\# rpm -Uvh https://repo.zabbix.com/zabbix/6.0/rhel/8/x86_64/zabbix-release-latest.el8.noarch.rpm

\# dnf clean all

b. Install Zabbix agent

\# dnf install zabbix-agent

c. Start Zabbix agent process

 

Start Zabbix agent process and make it start at system boot.

\# systemctl restart zabbix-agent

\# systemctl enable zabbix-agent

 

提醒：
1）修改客户端配置文件/etc/zabbix/zabbix_agentd.conf

将参数server  serverActive   hostname都指向服务端IP地址

2）确保客户端的selinux和firewalld.service 都处于关闭状态
