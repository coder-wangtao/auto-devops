zabbix的server安装和配置

安装参考文档：

https://www.zabbix.com/download?zabbix=6.0&os_distribution=centos&os_version=8&components=server_frontend_agent&db=mysql&ws=nginx

##### **a. Install Zabbix repository** 

\# rpm -Uvh https://repo.zabbix.com/zabbix/6.0/rhel/8/x86_64/zabbix-release-latest.el8.noarch.rpm
\# dnf clean all 

##### **b. Install Zabbix server, frontend, agent** 

\# dnf install zabbix-server-mysql zabbix-web-mysql zabbix-nginx-conf zabbix-sql-scripts zabbix-selinux-policy zabbix-agent 

##### **c. Create initial database** 

Make sure you have database server up and running. 

确保你已经安装了mysql,版本是5.7或8.0都可以(安装操作大家看下录屏)

Run the following on your database host. 

\# mysql -uroot -p
password
mysql> create database zabbix character set utf8mb4 collate utf8mb4_bin;
mysql> create user zabbix@localhost identified by 'password';
mysql> grant all privileges on zabbix.* to zabbix@localhost;
mysql> set global log_bin_trust_function_creators = 1;
mysql> quit; 

On Zabbix server host import initial schema and data. You will be prompted to enter your newly created password. 

\# zcat /usr/share/zabbix-sql-scripts/mysql/server.sql.gz | mysql --default-character-set=utf8mb4 -uzabbix -p zabbix 

Disable log_bin_trust_function_creators option after importing database schema. 

\# mysql -uroot -p
password
mysql> set global log_bin_trust_function_creators = 0;
mysql> quit; 

##### **d. Configure the database for Zabbix server** 

Edit file /etc/zabbix/zabbix_server.conf 

DBPassword=password 

##### **e. Configure PHP for Zabbix frontend** 

Edit file /etc/nginx/conf.d/zabbix.conf uncomment and set 'listen' and 'server_name' directives. 

\# listen 8080;
\# server_name example.com; 

##### **f. Start Zabbix server and agent processes** 

Start Zabbix server and agent processes and make it start at system boot. 

\# systemctl restart zabbix-server zabbix-agent nginx php-fpm
\# systemctl enable zabbix-server zabbix-agent nginx php-fpm 

##### **g. Open Zabbix UI web page** 

The URL for Zabbix UI when using Nginx depends on the configuration changes you should have made. 

访问页面：IP:8080   设置OK后，默认用户Admin默认密码zabbix
