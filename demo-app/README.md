# 演示应用

这是一个 React 基础项目，用于演示 DevOps 自动化平台的部署功能。

## 功能特性

- ✅ React 18 最新特性
- ✅ TypeScript 支持
- ✅ Vite 快速构建
- ✅ 响应式设计
- ✅ 现代化 UI 界面

## 安装依赖

```bash
cd demo-app
pnpm install
```

## 开发模式

```bash
pnpm dev
```

应用将在 `http://localhost:3010` 启动。

## 构建

```bash
pnpm build
```

## 预览构建结果

```bash
pnpm preview
```

## 工作流集成

此应用已集成到 `simple-deploy` 工作流中。执行工作流时，会自动启动此应用。

## 技术栈

- React 18
- TypeScript
- Vite
- CSS3
